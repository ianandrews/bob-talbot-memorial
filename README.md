# Bob Talbot Memorial

A public memorial honoring Robert J. “Bob” Talbot, preserving the supplied memorial page and its tributes.

View the memorial at **https://ianandrews.github.io/bob-talbot-memorial/**.

## Publishing

GitHub Pages publishes the root of the `main` branch. The page is `index.html`; `.nojekyll` keeps it a plain static site.

To update the memorial, edit `index.html` and push a commit to `main`. GitHub Pages will publish the update automatically.

## Local preview

Open `index.html` in a browser. No build step is required.
